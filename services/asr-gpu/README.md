# Bible Arena GPU ASR Service

This service hosts the Omnilingual ASR runtime behind a small authenticated FastAPI API.

## Current baseline

- Model: `omniASR_LLM_300M_v2`
- Initial language: Idoma (`idu_Latn`)
- GPU runtime: NVIDIA CUDA
- API: `POST /v1/transcribe`
- Health: `GET /health`

Meta's official Omnilingual ASR project documents the v2 model family and language-conditioned inference. The current reference pipeline expects audio file paths, so the API writes each upload to a temporary file before transcription.

## Local GPU smoke test

Build:

```bash
docker build -t bible-arena-asr .
```

Run with a GPU:

```bash
docker run --gpus all --rm \
  -p 8000:8000 \
  -e ASR_API_TOKEN='replace-with-a-long-random-token' \
  -e ASR_MODEL_ID='omniASR_LLM_300M_v2' \
  -e ASR_DEVICE='cuda' \
  bible-arena-asr
```

Health:

```bash
curl http://localhost:8000/health
```

Transcription:

```bash
curl -X POST http://localhost:8000/v1/transcribe \
  -H 'Authorization: Bearer replace-with-a-long-random-token' \
  -F 'audio=@idoma-sample.wav' \
  -F 'language_code=idu_Latn'
```

Do not commit real tokens. The production token should be generated by the deployment platform and stored as a secret.

## Hosted deployment

A managed GPU platform such as Hugging Face Inference Endpoints can run a custom Docker container. Keep the endpoint private/authenticated and expose only the `/v1/transcribe` route to the Supabase voice gateway.

The GPU endpoint should not be called directly by the browser.
