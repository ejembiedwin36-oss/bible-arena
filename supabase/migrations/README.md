# Supabase migrations

This directory tracks database migrations for Bible Arena so the repository documents the schema changes applied to the Supabase project.

The live Supabase migration history remains the source of truth for migrations already applied to production. New database changes should be represented here as SQL migration files as well as applied through the controlled Supabase migration workflow.

Recent voice/Idoma ASR database work includes reviewer security, speaker consent, secure voice contribution, consent withdrawal, speaker-level dataset assignments, reviewer administration, and ASR split-integrity checks.
