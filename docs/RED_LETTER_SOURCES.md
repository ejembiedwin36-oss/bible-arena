# Red-letter Bible data

The KJV red-letter reader loads verse text and `words_of_christ` marker ranges from [renniemaharaj/kjv-bible](https://github.com/renniemaharaj/kjv-bible), which describes the repository as MIT-licensed in its README. KJV text is public domain in many jurisdictions; check local reuse requirements. The upstream repository currently does not include a standalone LICENSE file.

Bible Arena only highlights words when its displayed verse exactly matches the source KJV verse. Any mismatch or missing annotation leaves the verse in normal text rather than incorrectly attributing speech to Jesus. Red-letter annotations are editorial interpretations, and editions may disagree, especially in John and Revelation.

The external corpus must remain reachable for annotations to load. The reader displays a warning if it cannot load the corpus.
